# Eval run, 2026-10-07 (evals 6-11)

**Method.** Each eval prompt was given to a fresh sub-agent told to act as Claude with this skill installed (it could read the skill folder, run the scripts and use web search; it could not ask follow-up questions and did not see the assertions). Its final reply was graded by hand against the eval's `assertions`. An assertion counts as a pass only when the reply fully satisfies it; a partial answer is a miss. Assertions for evals 9 and 11 were reworded before the run to match corrected facts (Brave unconfirmed, Meta tokens verified); none were changed after seeing answers. One run per eval and round, so treat the numbers as a smoke test, not a benchmark.

**Rounds.** Round 1 ran on the skill as first written. After round 1 the skill got three edits (a fuller Copilot quick answer, two new quick answers for snippet controls and robots-group questions, and a CJK word-count note in `verticals.md`) and evals 6, 7, 8 and 11 were re-run as round 2. Evals 9 and 10 were not re-run.

**Latest result per eval: 28 of 34 assertions fully met.**

**What the misses have in common.** All of them are secondary points dropped from a short "quick answer" (the skill asks for about 150 words). The core advice was right in every run, hedges were kept (Brave and Copilot impact labelled as unconfirmed, no invented crawler tokens, market shares sourced and caveated), and no reply promised an outcome. Two misses (eval 9's WebSearch remark, eval 11's word-count note) only apply when the agent runs a particular tool, so those assertions were written too broadly. The fixes made after round 1 moved the Copilot answer from a partial to a full pass on one point (verify, submit sitemap, enable IndexNow) and changed nothing else measurable.

**Limits.** Sub-agents are not the same as a user session in Claude's apps; skill triggering from natural phrasing was not tested (the agents were told the skill was installed). The quick-answer path was taken in every run, so the full six-phase audit was not exercised by these evals.
