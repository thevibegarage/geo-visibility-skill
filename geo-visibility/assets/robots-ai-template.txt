# HOW GROUPS WORK: a crawler obeys only the most specific group that names it. It does NOT
# also apply the "User-agent: *" group. So every private-path rule must be repeated in every
# group (or shared by listing several User-agent lines above one block, as below). Naming a
# bot with only "Allow: /" would silently open /admin/, /cart/ and the rest to it. Disallow lines
# come before "Allow: /" so parsers that use first-match order (not only longest-match) agree.
#
# NOTE on user-fetch agents: ChatGPT-User and Perplexity-User act on a live user's
# request, and both vendors state robots.txt rules may not apply to them. Listing
# them here is harmless, but blocking them via robots.txt is not guaranteed to work.
#
# NOTE on Bing: Bingbot feeds Bing, Microsoft Copilot and Bing-powered answers elsewhere (ChatGPT
# search is reported to use Bing-class results; DuckDuckGo and Yahoo are reported to as well). Blocking
# Bingbot removes you from all of them. Also verify the site in Bing Webmaster Tools and enable IndexNow.
