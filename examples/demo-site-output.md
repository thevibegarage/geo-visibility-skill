# Demo: the readiness checker on a deliberately flawed site

> **Real, unedited output.** Everything between the rules below is what `check_ai_readiness.py` prints when pointed at [`demo_site.py`](demo_site.py), a small fictional site ("Meridian CRM") that ships in this repo with flaws planted on purpose. No real company's site is involved, and you can reproduce it in two commands:
>
> ```bash
> python3 examples/demo_site.py &
> python3 geo-visibility/scripts/check_ai_readiness.py http://127.0.0.1:8765 --paths /pricing /features /blog/crm-for-agencies --issues-only
> ```
>
> This file is generated by `tools/make_demo_report.py` and a test fails if it drifts from what the tool really prints.

## Crawl mode: what `--crawl` adds

The links between the demo's pages are planted too. One more flag makes the checker follow them, as Googlebot, in at most 50 requests (what a bare `--crawl` allows; this run used 14):

```bash
python3 geo-visibility/scripts/check_ai_readiness.py http://127.0.0.1:8765 --paths /pricing /features /blog/crm-for-agencies --crawl --issues-only
```

Everything it adds is in the `links` area of the same report, and each crawl check is scored once like any other, so the score line becomes **73%** (5 failures, 8 warnings). These rows are copied from that run's JSON output:
